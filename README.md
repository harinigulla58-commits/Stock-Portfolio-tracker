# Stock Portfolio Tracker

## Objective
A simple Python project that calculates the total investment value of a stock portfolio using predefined stock prices.

## Features
- User enters stock names and quantities
- Uses a dictionary to store stock prices
- Calculates investment value
- Displays portfolio summary
- Saves results to TXT file
- Saves results to CSV file
- Shows portfolio distribution

## Technologies Used
- Python
- Jupyter Notebook
- Pandas (optional)
- Matplotlib (optional)

## How to Run

1. Clone the repository

2. Install dependencies

pip install -r requirements.txt

3. Open Jupyter Notebook

jupyter notebook

4. Run all cells
